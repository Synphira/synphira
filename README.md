*   **🧪 Quality Assurance & System Reliability**  
    Writing robust test suites across backends and frontends using **RSpec**, **Minitest**, **Jest**, **Vitest**, and **Playwright** end-to-end automation.
*   **🗄️ Database Management & Cloud Infrastructure**  
    Structuring, querying, and caching data using **PostgreSQL**, **MySQL**, **Redis**, **SQLite**, and **Supabase**, containerized via **Docker**, **Docker Compose**, and **Pterodactyl**, and deployed across **Cloudflare**, **GCP**, **Linux/Ubuntu**, and **Windows** with **GitHub Actions** CI/CD pipelines.
